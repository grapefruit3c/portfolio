## 技术特点

- **纯前端实现**：单个 `index.html` 文件，HTML + CSS + JavaScript，零外部依赖
- **响应式设计**：自适应手机、平板、桌面端浏览
- **暗色科技风**：蓝青渐变配色，滚动动画效果
- **即开即用**：双击文件即可在浏览器中打开，无需安装任何环境

## 本地预览

直接双击 `index.html` 文件即可在浏览器中打开预览。

## 部署方式

本网站通过 GitHub Pages 部署：

1. 将 `index.html` 推送至仓库 `main` 分支
2. GitHub 仓库 Settings → Pages → Source: Deploy from branch → `main` / `(root)`
3. 等待 1-2 分钟后访问线上地址

## 更新内容
